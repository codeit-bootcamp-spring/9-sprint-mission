entity란 시스템에서 핵심이 되는 데이터와 그 상태를 표현하는 도메인 객체

엔티티가 햄버거면 
그 안에는 구성요소가 있음 빵, 패티, 야채 등 
햄버거가 자기 구성요소를 알고 있는게 엔티티임

엔티티가 하는 일
1. 자기정보를 갖는다.
  - 나는 유저고 내 이름은 이거고 이메일은 이거다 (빵, 패티, 야채)

2. 자기 상태를 바꿀 수 있다.
  - 내 정보가 바뀌었다 (패티 추가, 야채 추가)

3. 자기 기준을 판단할수 있음
  - 내가 지금 접속 중인가? 

4. 만들어질때부터 제대로 만들어지기
  - 유저는 태어날때 ID랑 생성시간같은게 꼭 있어야 함



엔티티가 하면 안되는 일
1. 저장
  - 햄버거 스스로 냉장고에 못 들어감

2. 다른 애 불러오기
  - 햄버거가 주방장을 불러올수 없음

3. 전체 흐름 판단하기
  - 엔티티는 그냥 재료일뿐 흐름을 판단하는건 불가능

4. 화면이나 DTO를 신경쓸수 없음
  - 햄버거가 포장지 고민을 어케함
